Connect NovaBot

Installation and device pairing are handled from your licensed game slot in the Customer Hub.

1. Open your game slot

Register or sign in, activate a license or trial, and select the game slot you want to connect.

2. Install NovaBot Agent

Download the current NovaBot APK from the Setup flow in the Hub and install it on the rooted Android emulator or cloud phone that runs your game.

3. Pair with a six-digit code

Start NovaBot Agent, enter the six-digit pairing code in the Hub, and wait for the slot to show Connected.

4. Start your game

Open the supported game on the same device. Start and pause controls remain available from the browser.
