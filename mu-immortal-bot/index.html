DEVICE CONNECTION

Connect MU Immortal in four steps

Activate a license or available trial, install NovaBot on a supported rooted Android emulator, pair the device with the six digit code and open MU Immortal. The Hub reports the real Agent and game state.

Each licensed game slot keeps its own Agent connection. The normal app interface does not expose shared credentials or internal server controls.
