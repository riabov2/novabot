FAQ

Before you connect.

Practical answers about the Hub, Agent and licenses.

Where do I control NovaBot?

Use the Customer Hub at app.novabotmu.com from desktop or mobile. The Android Agent maintains the game connection.

Can one account manage several game characters?

Yes. Add multiple licenses to one account and switch between their independent game slots from the Hub.

What does one license cover?

One license is assigned to one game slot and one active emulator. The same emulator may reconnect without using a device change.

What happens when the bot is paused?

Pause stops NovaBot tasks for the selected slot, including hunting and events. The status changes to Pause until you start it again.

Does NovaBot expose technical Agent credentials?

No. The normal setup uses the NovaBot APK and a short pairing code. Agent credentials and transport settings stay out of the customer interface.

Can I try NovaBot first?

Eligible new accounts can create one 30 minute Trial slot from the Customer Hub.
