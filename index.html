FAQ

Before you connect

Clear answers about access, device requirements and everyday use.

Contact support →
What is NovaBot?

NovaBot is a browser-controlled automation platform for supported MU mobile games. A lightweight Android Agent connects the game device to the Customer Hub.

Which games are supported?

NovaBot supports MU Immortal, MU Monarch, MU Ascension and MU Lục Địa.

How does the free trial work?

An eligible account can activate one 30-minute trial and use it with a trial game slot. Removing that slot does not create another trial.

What is required to use NovaBot?

You need a NovaBot account, an active trial or license, a supported rooted Android emulator or cloud phone, and a stable internet connection.

Do I need a rooted Android emulator?

Yes. The current Android Agent requires root access on the emulator or cloud phone that runs the game.

Can I control my bot remotely?

Yes. Once the Agent is connected, the Customer Hub is designed for remote status and supported start or pause controls.

Can I run multiple game accounts?

One Hub account can manage multiple licensed slots. Each slot requires its own valid license and Agent connection.

How do licenses work?

One key is assigned to one game slot and one active emulator. Device transfer limits are enforced by the service.

What happens if my connection is lost?

The Agent reports an offline state and attempts to reconnect. The Hub does not show a fake online status while the device is unreachable.

How do I contact support?

Use the established NovaBot support channels listed on the contact page.
